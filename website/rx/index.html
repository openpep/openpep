COMO FUNCIONA

Você trabalha localmente e escolhe o que compartilhar.

O OpenPEP-Rx é instalado no computador e usado pelo navegador.

As receitas, os PDFs e o histórico ficam nessa instalação. Você pode consultar os documentos emitidos e manter cópias de segurança dos registros.

Para compartilhar, você configura um repositório online próprio ou usa o de um provedor. Só os PDFs autorizados são enviados. Assim, o paciente pode abrir o original mesmo quando o seu computador estiver desligado.

ACESSO

Abra sua instalação

Se o OpenPEP-Rx já está aberto neste computador, você volta ao editor e ao histórico.

Abrir OpenPEP-Rx local

Requer o serviço local em execução e aberto uma vez, neste navegador, pelo endereço exibido no terminal.

Como iniciar a instalação local

O código está em apps/openpep-rx, no repositório do OpenPEP. Com Node.js 24, execute nessa pasta npm ci e npm run local; para assinar no Mac, também npm run build:signer. Abra uma vez o endereço exibido no terminal (http://127.0.0.1:4197/abrir?chave=…): ele vale para uma execução e para um navegador. Ainda não há instalador. As instruções completas estão no README do módulo.

ANTES DE COMEÇAR

Dúvidas frequentes

É um site ou um aplicativo?

É uma aplicação web para rodar localmente: você usa o navegador, mas um serviço no seu computador guarda os dados e executa o fluxo de emissão. O portal de numeração e o repositório de PDFs são serviços online separados.

Cada profissional pode ter seu ambiente?

Essa é a proposta: uma instalação local e um repositório online próprio ou oferecido por um provedor. A implantação exige configurar domínio, armazenamento, credenciais de publicação e backups. Ainda não há cadastro automático que crie essa infraestrutura.

Funciona sem internet?

O armazenamento e o preparo são locais. O VIDaaS Connect usa certificado em nuvem e precisa de internet, assim como o portal SNCR e o compartilhamento online. Local não significa que todas as etapas funcionam desconectadas.

Quem pode abrir o documento compartilhado?

Quem tiver o link completo ou o QR pode acessar aquele PDF enquanto o link estiver ativo, sem login no ChatGPT. Trate o link como confidencial. Desativá-lo não apaga cópias já baixadas nem cancela a receita.

Já está disponível no GitHub?

Sim. O código está em github.com/openpep/openpep, na pasta apps/openpep-rx, sob a licença AGPL-3.0-or-later; marca e dependências têm avisos próprios. Ainda não há instalador: a instalação é feita a partir do código.

Já posso usar para atendimento?

Esta é uma versão experimental para avaliação com dados fictícios. Testes de interface não equivalem à validação clínica nem à confirmação de emissão SNCR em produção. A liberação depende das validações e configurações necessárias.
