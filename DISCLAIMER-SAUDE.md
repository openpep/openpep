# Aviso de saúde

O OpenPEP está em alfa experimental, sem liberação para atendimento clínico ou armazenamento de dados reais de pacientes. Os ensaios devem usar somente dados sintéticos.

O software registra informações e pode preparar rascunhos para revisão. Ele não toma decisões de diagnóstico ou prescrição e não substitui o julgamento do profissional responsável.

Nenhuma certificação ou conformidade deve ser presumida. Quando houver testes, auditorias ou certificações, o repositório identificará o escopo, a versão e a data correspondentes.

Este documento é um aviso sobre o estado do projeto. Ele não altera a licença do software nem cria uma restrição adicional de copyright.
