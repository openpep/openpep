Code embedded in @pdf-lib/fontkit 1.1.1 (dist/fontkit.es.js)

@pdf-lib/fontkit ships a single prebuilt file that already contains the
third-party code below. This list comes from the upstream rollup.config.js and
yarn.lock at Hopding/fontkit commit 72b8e42b (version 1.1.0; npm 1.1.1 was
published two weeks later; the repository has no later commit), cross-checked against the
code present in dist/fontkit.es.js. Versions follow that yarn.lock. License
texts come from each package's npm tarball; where a package ships no license
file, the declared license is stated. pako is listed separately: it stays an
external dependency of fontkit.

Not evaluated: terms for the data tables derived from Unicode Character
Database and unicode.org mapping files (unicode-properties, iconv-lite).
