O ambiente web envia ao SNCR somente os dados profissionais e o pedido de numeração. Uma cópia do resultado fica disponível aqui para recuperação; receitas, PDFs e assinatura permanecem no computador.

Emitente

Confira os dados com o titular do certificado VIDaaS. Serão usados nos PDFs e nos pedidos de numeração.

Banco na pasta local

SQLite guarda lotes, números, reservas, receitas e PDFs assinados.

Para compartilhar a pasta com o OpenPEP, configure OPENPEP_DATA_DIR no arquivo .env. O Rx usa a subpasta prescricao. Para definir uma pasta exclusiva, use OPENPEP_RX_DATA_DIR. Reinicie o módulo após mudar o caminho; o banco existente não é movido automaticamente.

O navegador acessa o arquivo pelo serviço local. Receitas e PDFs permanecem neste computador.

Ambiente SNCR

O ambiente define qual estoque será usado nas receitas. Para importar lotes do portal, não é necessário ativar pedidos diretos.
