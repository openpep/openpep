Abra o assinador no computador

Esta versão usa macOS e o VIDaaS Connect instalado e autenticado. Na pasta do módulo, execute:

npm ci
npm run build:signer
npm run local

Abra o assinador local. A compilação requer Xcode Command Line Tools.
